# WhatsApp Fynd

A WhatsApp integration project for finding and discovering content.

## Features

- WhatsApp integration
- Content discovery
- Search functionality

## Installation

```bash
# Clone the repository
git clone https://github.com/saud-hyd/whatsapp-fynd.git

# Navigate to the directory
cd whatsapp-fynd

# Install dependencies
npm install
```

## Usage

```bash
# Start the application
npm start
```
